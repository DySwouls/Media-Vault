# 📚 Media Vault

> Minha biblioteca pessoal para organizar tudo o que assisto, jogo e leio.

## 📖 Sobre

O **Media Vault** é um projeto pessoal criado para centralizar toda a minha biblioteca de entretenimento em um único lugar.

A ideia surgiu da dificuldade de encontrar uma plataforma que reunisse animes, filmes, séries, jogos, mangás e livros com a liberdade de organização que eu queria. Em vez de depender de vários serviços diferentes, decidi desenvolver minha própria solução.

Além de servir como ferramenta para uso diário, este projeto também será uma forma de praticar desenvolvimento web e integração com APIs.

---

## 🎯 Objetivos

* Registrar tudo o que já assisti, joguei e li.
* Organizar obras por categorias.
* Salvar avaliações e reviews pessoais.
* Acompanhar meu progresso.
* Sincronizar automaticamente entre computador e celular.

---

## 🚧 Funcionalidades planejadas

* 🎌 Animes e Mangás
* 🎬 Filmes
* 📺 Séries
* 🎮 Jogos
* 📚 Livros

Cada obra poderá conter:

* Capa
* Informações gerais
* Status (Assistindo, Concluído, Quero ver, etc.)
* Nota
* Review
* Favoritos
* Histórico pessoal

---

## ⚙️ Tecnologias

### Front-end

* HTML
* CSS
* JavaScript

### Back-end

* Servidor para autenticação e sincronização dos dados
* Banco de dados para armazenamento da biblioteca

### APIs

As informações das obras (capas, sinopses, gêneros, temporadas, etc.) serão obtidas através de APIs públicas, enquanto minhas informações pessoais (listas, notas, reviews e progresso) serão armazenadas no servidor do projeto.
